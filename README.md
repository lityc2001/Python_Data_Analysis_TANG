# Python_Data_Analysis_TANG
Python_Data_Analysis

## 概要 / Overview

### 日本語
このフォルダには、Pythonを使用して作成したデータ分析・機械学習の実践プロジェクトをまとめています。

各プロジェクトでは、データの読み込み、データクリーニング、探索的データ分析（EDA）、可視化、統計分析、機械学習モデルの構築・評価など、一連のデータ分析プロセスを実践しています。

### English
This folder contains practical data analysis and machine learning projects developed using Python.

Each project covers different stages of the data analysis workflow, including data loading, data cleaning, exploratory data analysis (EDA), visualization, statistical analysis, machine learning model development, and model evaluation.
